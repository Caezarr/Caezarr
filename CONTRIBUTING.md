# Contributing

This repo is the public GitHub profile README for **Caezarr** (Gabriel Rance).

## Changes welcome

- Typo / clarity fixes in `README.md`
- Broken badge or link fixes
- Small SVG / script polish that improves the profile render

## How to propose a change

1. Open a PR against `main` with a short description of what changed and why.
2. Keep diffs focused — no drive-by refactors of generated assets unless needed.
3. Do not commit secrets, tokens, or personal contact data beyond what is already public.

Security reports: see `SECURITY.md`.
