# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security reports about this profile or linked projects.

Email **gabriel.rance@ensam.eu** with:

- a short description of the issue
- steps to reproduce
- impact / affected surface

You should get an acknowledgement within a few business days. Please give a reasonable window before any public disclosure.

## Scope

This repository hosts the public GitHub profile README for Caezarr (Gabriel Rance). Security reports that belong to a product repo should go to that repo's `SECURITY.md` when present.
